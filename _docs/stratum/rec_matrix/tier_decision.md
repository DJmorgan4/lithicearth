# REC Tier Decision Matrix

## UST Scenarios
| Condition | Correct Tier | Reasoning |
|-----------|-------------|-----------|
| Active UST, no release documented | REC | Material threat of future release |
| UST removed, closure letter with NFA | HREC | Regulatory closure, no controls |
| UST removed, closure letter with monitoring | CREC | Controls remain active |
| UST removed, NO closure letter | REC | Cannot confirm clean closure |
| UST on adjacent property, release migrating | REC | Actual release, migration pathway |
| UST on adjacent property, no migration | De Minimis or No REC | No pathway to subject property |
| Petroleum release, active remediation | REC | Active release, not resolved |
| Petroleum release, NFA issued | HREC | Regulatory closure confirmed |

## Dry Cleaner Scenarios
| Condition | Correct Tier | Reasoning |
|-----------|-------------|-----------|
| Current dry cleaner on site | REC | PCE/TCE use, high release probability |
| Former dry cleaner, no investigation | REC | Historical use without closure |
| Former dry cleaner, NFA issued | HREC | Confirmed closure |
| Adjacent dry cleaner, upgradient | REC | Migration pathway exists |
| Adjacent dry cleaner, downgradient | De Minimis | No credible migration pathway |

## Common Tier Errors
- Calling a removed UST without closure letter a CREC (wrong — it's a REC)
- Calling an NFA-issued petroleum release a CREC (wrong — it's an HREC)
- Calling an active release a HREC (wrong — must be REC until NFA)
- Downgrading to De Minimis without documented regulatory concurrence
