# Phase I ESA Language Audit Standards

## Prohibited Phrases (Non-Standard)
| Prohibited | Standard Replacement |
|------------|---------------------|
| "appears clean" | "no RECs identified" |
| "looks clean" | "no RECs identified" |
| "seems to be uncontaminated" | "no evidence of contamination was identified" |
| "probably no concern" | remove — qualify findings factually |
| "minor spill" | "release" (never minimize) |
| "old contamination" | "historical release" |
| "cleaned up" | "remediated" or "addressed to regulatory closure" |
| "no problems found" | "no RECs were identified" |
| "environmentally safe" | EP cannot make this determination |
| "no environmental issues" | "no RECs, CRECs, or HRECs were identified" |

## Overstatement Flags
- Claiming "no RECs" when UST closure documentation was not obtained
- Stating property is "clean" based on visual inspection alone
- Concluding no vapor encroachment without completing ASTM E2600 screening
- Stating "no impact" from adjacent sites without hydrogeologic basis

## Understatement Flags  
- Documenting a release but not calling it a REC
- Noting UST removal without assessing closure documentation
- Listing regulatory database hits without assessing their significance
- Identifying dry cleaner use without REC determination

## Professional Judgment Qualifiers (Required Language)
"In the professional judgment of the environmental professional..."
"Based on reasonably ascertainable information..."
"To the extent feasible given inherent limitations..."
"This opinion is based on conditions observed at the time of the site visit..."
